Integrações e webhooks

Informe URLs HTTPS de funções de backend que recebem formulários e encaminham mensagens. Não cole links secretos de Discord Webhook aqui.

Deve ser uma função/servidor que valida dados e envia para o Discord pelo lado do servidor.
Para visitas globais reais, o site e o painel devem enviar/ler estatísticas deste backend ou Supabase.
Nunca use service_role, chave secreta ou tokens privados no HTML. As tabelas precisam de políticas RLS seguras.
Segurança: não existe forma segura de esconder um Discord Webhook secreto em um HTML público. Guarde a URL real do webhook em Secrets/variáveis de ambiente do backend; aqui entra somente o endpoint HTTPS do backend.
